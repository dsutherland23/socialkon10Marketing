# 3. DESIGN PHILOSOPHY

Do NOT create a generic SaaS website.

Avoid:

* Generic hero + 3 cards
* Excessive rounded cards
* Purple/blue AI gradients
* Inter everywhere
* Excessive glassmorphism
* Random floating shapes
* Animation for the sake of animation
* Every section looking identical
* Huge amounts of text
* Stock-photo-heavy layouts
* Template-looking pricing tables
* Excessive shadows
* Boring centered layouts

The site should feel:

**Creative**
**Confident**
**Premium**
**Editorial**
**Interactive**
**Modern**
**Commercial**
**Strategic**
**Caribbean-rooted but globally competitive**

Use asymmetry, strong typography, controlled whitespace, large imagery, intentional motion and distinct visual identities for each service department.

# 28. PAYMENT SYSTEM

Payment architecture must be provider-agnostic.

Primary requirements:

* Credit/debit cards
* PayPal
* Payment links
* Deposit payments
* Full payments
* Recurring subscriptions
* Invoices
* Refund handling
* Payment confirmation
* Failed-payment handling
* Webhooks
* Transaction records

Because Social Kon10 operates from Jamaica, payment provider availability must be verified before production.

PayPal currently advertises Jamaica business checkout supporting PayPal and major cards. Stripe's current global availability list does not list Jamaica as a directly supported country, so Stripe should not be assumed as the primary processor for a Jamaican merchant.

Implement a payment abstraction layer:

```text
PaymentProvider
    |
    +--- PayPal
    |
    +--- Stripe
    |
    +--- Future Caribbean provider
```

This allows another provider to be added without rebuilding checkout.
